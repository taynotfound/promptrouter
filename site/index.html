Stop paying cloud prices for rename this variable.

promptrouter judges every coding task and runs the easy 80% on your own GPU, free and private. It only reaches for the cloud when the work actually needs it.

Install Source

What it does

$ route --explain "rename the variable foo to bar"
[judge] EASY trivial rename
→ ollama/qwen3-coder:30b  (local, free)
$ route --explain "debug my websocket reconnect loop under load"
[judge] HARD real concurrency debugging
→ hermes/claude-sonnet-5
$ route --explain "design a lock-free MPMC queue with hazard pointers"
[judge] EXPERT hard concurrency, easy to get wrong
→ hermes/claude-opus-4.8

A fast local model judges the task in about 0.3s, then routing walks a fallback chain you define in one YAML file.

Why

Free for the common case

Renames, boilerplate, and small fixes run on hardware you already own. They never touch a paid API.

Private by default

The local tier keeps that code on your machine. Nothing leaves the box unless the task is escalated on purpose.

One file to tune

Models, tiers, and fallback order are plain YAML. Swap any Ollama, OpenRouter, or Hermes model. Nothing hardcoded.

Install


    
A single static binary, no runtime to install. After installing, run route --explain "rename a variable".
